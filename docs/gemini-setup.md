# Gemini без платного API-тарифа

4 октября 2026. Backend переключён с OpenAI на Gemini Developer API. Основная модель — `gemini-3.5-flash-lite`; согласно текущей [таблице Google](https://ai.google.dev/gemini-api/docs/pricing), для неё есть бесплатные входные и выходные токены в Free Tier. Настоящий ключ и качество модели ещё не проверены.

## Что нужно сделать

1. Открыть [ключи Google AI Studio](https://aistudio.google.com/apikey), войти в Google и создать ключ для проекта на **Free Tier**.
2. Проверить тариф проекта. Не включать биллинг, не привязывать проект к платному billing account и не использовать уже оплачиваемый проект, если цель — нулевые расходы.
3. Добавить настройки в локальный `backend/.env`:

```dotenv
GEMINI_API_KEY=your_actual_key
MODEL_NAME=gemini-3.5-flash-lite
```

`MODEL_NAME` можно не указывать: эта модель уже выбрана по умолчанию. Пример выше содержит заглушку, не рабочий ключ. Существующие `QLOO_API_KEY`, `DATABASE_URL` и другие настройки сохраняются. Файл исключён из Git; ключ не отправлять в чат и не помещать в README. После изменения настроек перезапустить backend.

Для полного сценария всё ещё нужен отдельный ключ Qloo. `/api/health` показывает наличие конфигурации, но не проверяет ключ запросом к Google.

## Как ограничены расходы

Адаптер обращается только к Gemini Developer API. Vertex AI, OpenAI и автоматический переход на другие модели не используются. Скрытые повторы SDK отключены; собственные бюджеты агента и общий таймаут остаются. При исчерпании квоты агент возвращает явный fallback и уже полученную фактическую подборку, не переключается на платную модель.

Это **не проверка биллинга**: один и тот же API доступен бесплатным и платным проектам. Если проект уже связан с платным тарифом, запросы могут оплачиваться. Код не может обещать нулевой счёт такого аккаунта. Отдельная подписка на Gemini или ChatGPT не нужна для этого подключения.

Бесплатный API имеет лимиты по запросам и токенам. Проверять доступную квоту нужно в своём AI Studio: [официальная документация лимитов](https://ai.google.dev/gemini-api/docs/rate-limits). Один агентный запуск делает несколько модельных обращений, а не один.

Google указывает использование данных бесплатного тарифа для улучшения продуктов. Для тестов отправляем только обычные культурные интересы; пароли, личные документы и чувствительную информацию не передаём. Условия обработки нужно учитывать отдельно перед публичным выпуском. [Тарифы и использование данных](https://ai.google.dev/gemini-api/docs/pricing).

## Проверки

Обычные автоматические тесты не требуют ключа и не обращаются к реальной модели. Они используют сценарную модель и HTTP-заглушки нативного Gemini SDK. Проверены вызов инструментов, возвращение результата инструмента в следующий запрос, структурированный план, отсутствие скрытых повторов, обработка 429/500, сетевого сбоя и таймаута.

Когда оба ключа готовы, из `backend` можно явно запустить живой тест:

```sh
RUN_AGENT_LIVE=1 uv run pytest tests/test_live.py::test_live_grounded_agent_plan -q
```

Это расходует квоту выбранного проекта; при платном тарифе возможна оплата. Без явного флага тест пропускается. Успех одного сценария не заменяет дальнейшую оценку качества рекомендаций.
